# AI-Based Smart Door Access Control System Using Face Recognition

## Overview

This project is an AI-based smart door access control system designed to provide secure and contactless authentication using face recognition technology. The system identifies authorized users in real time and automates the door access process using computer vision and machine learning techniques.

---

## Features

* Real-time face detection and recognition
* Secure and automated access control
* Contactless authentication system
* User verification and monitoring
* Improved security and convenience

---

## Technologies Used

* Python
* OpenCV
* AI/ML
* HOG + SVM
* ResNet (CNN)

---

## Workflow

1. Capture real-time image input
2. Detect faces using HOG + SVM
3. Extract facial features using ResNet (CNN)
4. Compare facial encodings with stored data
5. Grant or deny access based on verification
